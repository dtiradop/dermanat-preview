# Laboratorios Dermanat · Preview

[Ver la demostración](https://dtiradop.github.io/dermanat-preview/)

Vista estática del WordPress local de Laboratorios Dermanat: 12 páginas, 42 fichas, catálogo con filtros y cotizador con 21 referencias tarifadas.

Los valores son pesos colombianos por unidad, antes de IVA, con cinco rangos de cantidad por referencia. Las fórmulas sin tarifa se muestran como “Precio por cotizar” y no se suman como productos gratuitos. La unidad del contenido, el envase y la etiqueta se confirman con el equipo comercial.

El archivo `dermanat-preview.zip` contiene los HTML, estilos, imágenes y scripts. GitHub Actions lo descomprime y publica en GitHub Pages.

Los formularios simulan el flujo y no envían ni almacenan datos de contacto. La selección se conserva en el navegador y puede compartirse por WhatsApp mediante una acción explícita del visitante.

La edición con Elementor continúa en el WordPress local. Este repositorio no contiene bases de datos, PHP ni credenciales.
