# Dermanat Preview

[Ver la demostración](https://dtiradop.github.io/dermanat-preview/)

Vista estática exportada del WordPress local de Laboratorios Dermanat: 12 páginas, 31 fichas, catálogo con filtros y un cotizador sin precios.

El archivo `dermanat-preview.zip` contiene todos los HTML, estilos, imágenes y scripts de la vista. GitHub Actions lo descomprime y publica su contenido en GitHub Pages.

Los formularios simulan el flujo y no envían ni almacenan datos de contacto. La selección de fórmulas se conserva en el navegador y puede compartirse por WhatsApp mediante una acción explícita del visitante.

La edición con Elementor continúa en el WordPress local. Este repositorio no contiene bases de datos, archivos PHP ni credenciales.
